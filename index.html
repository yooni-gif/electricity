직렬 연결: 회로의 모든 지점에서 전류의 세기가 같습니다 ($I = I_A = I_B$).
병렬 연결: 전체 전류는 각 가지에 흐르는 전류의 합과 같습니다 ($I_{전체} = I_A + I_B + I_C$).

직렬연결과 병렬연결 비교 정리

구분 ⚡ 직렬연결 (Series) 🔀 병렬연결 (Parallel)
전류의 경로 전류가 흐르는 길이 오직 1개 전류가 나누어 흐르는 길이 여러 개
합성 저항 ($R$) 전구를 추가할수록 전체 저항 증가 ($R = R_1 + R_2$) 전구를 추가할수록 전체 저항 감소 ($\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}$)
전구의 밝기 전구 개수가 늘어나면 어두워짐 전구가 늘어나도 각 전구의 밝기는 유지됨
전구 하나가 끊어질 때 전체 회로 차단 (모든 전구 꺼짐) 다른 가지는 정상 전류 흐름 (계속 켜짐)
생활 속 활용 예시 퓨즈, 장식용 미니 전구(일부), 화재경보기 스위치 가정집 콘센트, 건물 전등, 멀티탭, 가전제품
